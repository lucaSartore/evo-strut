\chapter{Monte Carlo Stiffness Evaluation}
\label{cha:stiffness_algo}

The biggest hurdle that we face when trying to optimize support structure for FDM printing is the
wobble effect \ref{sec:wobble-test}, as we explained this is unique to the aforementioned
technology, and is therefore not something that has been tackled by the existing literature.
This problem is fundamentally caused by a lack of horizontal stiffness (i.e. by the support being too compliant
to horizontal forces that are applied to it by the nozzle).
Solving this issue require having at least an idea of what the stiffness is in any point of the support structure,
and this of course require an algorithm that is able calculate it.
The problem is of course not new, and there are therefore well studied solutions in literature that we will take a look
in a bit, however a key constraint that we have is that the algorithm must be fast (as it will be placed in the
evaluation loop of a genetic algorithm). This speed is not something that is easily achieve with existing solution,
and this is why we are proposing a new monte carlo approach for stiffness evaluation, that sacrifice a bit of accuracy
in order to achieve unmatched speed.

\section{Problem Statement}

The problem itself is extremely simple: given a structure of a support, we want to know the stiffness of it 
in all of it points. ``Stiffness'' can be broadly defined as the amount of force that is required to move or twist the structure by a certain
amount, and can be represented by a 6x6 stiffness matrix (more details on section \ref{sec:stiffness_def}).
Defining the problem for an arbitrary support structure can be complicated, fortunately (as we discussed in section \ref{sec:obj})
we have limited the support structure's search space to the ``struct'' topology (or to be more precise, a ``rigid frame'').
The problem has two more ``boundaries conditions'', namely the requirement that it need to be as fast as possible, and the fact 
that exact solutions are not needed, as long as solutions are accurate enough. 
By synthesizing these requirements and constraints, we can define the problem as follows:
\\
\\
\noindent\textit{Given a \textbf{rigid frame (\ref{sec:rigid_frame})} } find an algorithms, that is able to calculate 
an approximation of the \textbf{Stiffness Matrix (\ref{sec:stiffness_matrix})} for every \textbf{node} in the frame
in a timely manner.


\section{Definitions and Notations}

\subsection{Rigid Frame}
\label{sec:rigid_frame}

A rigid frame can be defined as a \textbf{set of points} in three dimensional space.
Every point can be connected to one or more other points through a \textbf{beam}.
The connections form a graph that must be fully connected.
All beams must be made of the same material, and have the same cross-section, however
they do not need to be the same length.
Each \textbf{point} (that we can also call \textbf{node}) is \textbf{rigid}
meaning that the beams that are attached to it are not allowed to rotate and must
maintain the same position and orientation relatively to each others. figure \ref{fig:rigid_frame} show some example of what are considered valid rigid frames
